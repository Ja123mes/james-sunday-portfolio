My work

Projects I have built

Three sample projects from my first semester of web development. Each one has a working demo you can try.

Project 01

SpendWise Expense Tracker

HTMLCSSJavaScript

A simple tool that helps a student see where their money goes. You add an expense with a name, category and amount, and the page keeps a running total and a breakdown by category.

  • Add and delete expenses
  • Running total and category totals
  • Built with arrays and loops

Live demo GitHub

Project 02

Web Basics Quiz

HTMLCSSJavaScript

A short multiple-choice quiz about HTML, CSS and JavaScript. It checks each answer straight away, keeps your score and shows a final result at the end.

  • Questions stored in an array of objects
  • Instant feedback on every answer
  • Final score and a restart button

Live demo GitHub

Project 03

Campus Events Board

HTMLCSS GridJavaScript

A page that lists study sessions, workshops and social events. Visitors can filter by category and save the events they want to attend.

  • Filter buttons for each category
  • Save and unsave events with a counter
  • Responsive grid layout

Live demo GitHub

Reflection

What these projects taught me

Plan before coding

Sketching the page and listing the features first saved me a lot of rewriting.

Test small pieces

Checking each button as I built it made bugs much easier to find.

Keep code readable

Clear names and short comments help me understand my own code days later.
