# James Sunday - Student Portfolio and Academic Planner

**COS 106 - Introduction to Web Technologies | Term Project**
**Author:** James Sunday, MIVA Open University

A responsive multi-page portfolio website with a built-in academic planner. It is made with plain HTML, CSS and JavaScript (no frameworks).

**Live site:** _add your Netlify link here_

## Pages

| Page | File | What it does |
|------|------|--------------|
| Home | `index.html` | Welcome message, photo, biography, featured projects and journey |
| About | `about.html` | Education table, career goals, skills, hobbies and learning approach |
| Projects | `projects.html` | Three projects with descriptions, screenshots and links |
| Planner | `planner.html` | Add, complete and delete tasks, with priorities, filters and a progress bar |
| Contact | `contact.html` | Contact details, validated form and FAQ |

## Features

- Dark, responsive design that works on phones, tablets and computers (Flexbox and CSS Grid)
- Mobile menu, hover effects and animations
- Planner built with arrays, functions, event handling and DOM manipulation (tasks are saved in the browser)
- Contact form validation: no empty fields, valid email format, digits-only phone number
- Background ambient sound with an on/off button
- Semantic HTML with tables, lists, images, links, forms and audio
